# Store Submission Checklist

## Before Submitting

1. Test the unpacked `tabmix` folder in Chrome.
2. Confirm the popup works on normal websites with audio or video.
3. Keep permissions limited to what TabMix needs.
4. Use the ZIP file from `dist/tabmix-1.0.0.zip`.

## Chrome Web Store

1. Go to the Chrome Web Store Developer Dashboard.
2. Create or open the TabMix item.
3. Upload `dist/tabmix-1.0.0.zip`.
4. Add screenshots, description, category, and privacy answers.
5. Link to `PRIVACY.md` or publish the same privacy text on a public web page.
6. Submit for review.

## Microsoft Edge Add-ons

1. Go to Microsoft Partner Center for Edge Add-ons.
2. Create a new extension submission.
3. Upload `dist/tabmix-1.0.0.zip`.
4. Fill out the listing, privacy, and certification forms.
5. Submit for review.
